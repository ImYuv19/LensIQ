LensIQ Technical Architecture Specification 2026.
Created by The Ambitious Lens Studio by uvRaj.
Section 1.1: Vector Indexing and Hybrid Search Engine
The LensIQ query pipeline implements reciprocal rank fusion (RRF) combining dense 768-dimensional vector embeddings generated by Google Gemini embedding-001 with PostgreSQL full-text tsvector search.
The default reciprocal rank constant k is set to 60. Dense search uses an HNSW index on the chunks embedding column with cosine distance metrics.

Section 1.2: AI Generation and Provider Resiliency
Gemini 3.5 Flash serves as the primary generative inference engine. If Google Gemini experiences rate limiting, service degradation, or timeouts exceeding 30 seconds, the inference engine automatically fails over to Groq executing openai/gpt-oss-20b.
Synthetic, mock, or deterministic completions are strictly disallowed across all execution tiers.

Section 1.3: Data Isolation and Security
Tenant isolation is enforced cryptographically using local HMAC-SHA256 JWT tokens. Every document chunk stores the user's UUID in the user_id column. Inverted indices and vector similarity queries strictly restrict partition scans to the authenticated caller's identity.
